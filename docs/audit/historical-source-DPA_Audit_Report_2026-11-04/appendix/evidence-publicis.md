## 0. Method note (read before citing)

All job evidence is hosted on **careers.publicisgroupe.com** (Publicis Groupe's Phenom/Jibe careers platform) or its sub-brand hubs (`/starcom`, `/razorfish`, `/saatchiandsaatchius`, `/cj`, `/usmsinfluentialnetwork`, `/mslcanada`, `/publiciscollective`, `/publicisgroupeanz`, `/phm`). Source owner for every careers URL is **Publicis Groupe Holdings B.V** (site footer: "Publicis Groupe Holdings B.V Careers"). Direct `fetch_content` of any JD URL returns only a client-side rendering shell ("Join our talent pool" boilerplate) — this happens even for postings indexed October 2026, so the shell is a platform artifact, **not** proof a posting is expired. JD text and posted dates in this audit therefore come from search-engine-indexed extracts of the employer's own URLs (employer-authored content, employer-hosted). Full-text archival in a browser remains outstanding (see §5). Postings without a visible indexed date are marked "date not shown in indexed extract".
